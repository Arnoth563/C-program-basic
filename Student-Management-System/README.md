# Student Management System in C

A console-based Student Management System developed in C.

## Features

- Create a new student database
- Load existing student database
- Add students dynamically using realloc()
- Search students by name
- Search students by student number
- Display all student records
- Generate statistics reports
  - Highest Mark
  - Lowest Mark
  - Mean
  - Median
  - Mode
- Save records using fwrite()
- Load records using fread()

## Concepts Used

- Structures
- Dynamic Memory Allocation
  - calloc()
  - realloc()
  - free()
- File Handling
  - fopen()
  - fwrite()
  - fread()
  - fclose()
- Strings
  - fgets()
  - strcmp()
  - strcspn()
- Modular Programming
- Searching Algorithms
- Statistical Analysis
